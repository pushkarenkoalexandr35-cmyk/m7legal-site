# M7Legal — новый многостраничный сайт юридической фирмы

Прототип расширения действующего [M7Legal](https://m7legal.ru/) до полноценной юридической фирмы (бизнесу, частным лицам, арбитраж, договоры, корпоративные вопросы, недвижимость, международные сделки). Исходный сайт на **m7legal.ru не изменён**.

## Предварительный просмотр

**https://dev.labned.ru/m7legal-preview-20261009/**

Предпросмотр размещён в отдельном каталоге уже существующего тестового сайта `dev.labned.ru`. Основные файлы LABNED, действующий сайт M7Legal и серверные конфигурации не менялись.

На предварительном просмотре:
- установлены `noindex, nofollow`;
- формы обращений намеренно **не отправляются**, чтобы исключить тестовые лиды;
- Яндекс.Метрика выключена, чтобы не портить статистику боевого сайта;
- GitHub Actions/Pages и другие CI/CD не запускались;
- каталог `.git` на веб-сервер не размещён;
- все внутренние переходы переписаны в изолированный префикс предпросмотра.

## Состав

- Главная, каталог услуг, разделы услуг, практика, о компании, цены, контакты, команда и профиль управляющего партнёра.
- 15 исторических страниц: услуги проверки Китая и юридические документы с исходными URL и отдельным `legacy.css`.
- Общие стили `styles.css`, `site-pages.css`, меню `site.js`.
- Форма `m7-form.js` сохраняет существующий API-формат, но требует тестирования в staging с рабочим backend перед запуском.
- Подробная карта сайта и критерии запуска — [SITE-PLAN.md](SITE-PLAN.md).

## Статус

**Проверено:** 30 HTML-страниц предпросмотра отдают HTTP 200; 35 внутренних ссылок/ресурсов проверены по HTTP; X-Robots-Tag `noindex` присутствует на всех; случайной публикации `.git` нет. Исправлена навигация старых якорных ссылок в предпросмотре.

**Подтверждённая биография:** сведения об Артеме Федорове перенесены с действующего сайта M7Legal. Фотография получена из существующих материалов LABNED, оптимизирована до 17 КБ и сохранена в том же репозитории. Вымышленных сотрудников и побед в делах не добавляли.

**Не проверено:** визуальное отображение в реальном браузере на всех разрешениях, доступность интерфейса в реальном устройстве и реальная отправка заявок. До размещения в production эти проверки обязательны.

**До запуска:** подтвердить у команды действительную квалификацию по новым практикам, стоимость услуг, юридические сведения, контент; затем отдельно проверить мобильную версию, формы, SEO и подготовить откат.

Никаких новых платных сервисов и автоматических GitHub Actions.
