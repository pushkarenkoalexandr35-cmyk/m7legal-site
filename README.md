# M7Legal — новый сайт юридической фирмы (прототип)

Отдельный репозиторий для новой версии сайта [m7legal.ru](https://m7legal.ru/), вдохновлённой **архитектурой доверия** Nobele, но с собственной айдентикой M7Legal. Текущий боевой сайт хранится отдельно в `m7legal-site-new` и этим проектом **не изменяется**.

## Задача
- Показать M7Legal как юридическую фирму, сохранить действующую специализацию на проверке китайских контрагентов.
- Упростить навигацию: услуги → примеры задач → подход → команда → цены → контакт.
- Не придумывать судебные победы, отзывы, рейтинг или статистику.
- Оставить существующие SEO-адреса действующих услуг и адаптировать их дизайн отдельным этапом.
- Сохранить текущую логику заявки: `GET /api/lead` → токен, `POST /api/lead`, согласие на ПД, honeypot, событие Метрики.

## Файлы
- `index.html` — главная страница.
- `styles.css` — адаптивная дизайн-система (без сборщика и платных сервисов).
- `site.js` — мобильное меню.
- `m7-form.js` — существующий обработчик формы (подготовлен к тому же backend API).

## Статус и эксплуатация
**Только прототип.** Не включать GitHub Actions/Pages. Не выполнять автоматический деплой. Перед выводом в production провести проверку форм, мобильного UX, SEO и перенести существующие страницы/политику. Кнопки отдельных услуг ведут на рабочие страницы m7legal.ru. На прототипе стоит `noindex`, при запуске заменить на индексируемое значение и проверить canonical. API заявки работает **только на домене с существующим nginx proxy /api/lead**.

## Следующие шаги
1. Согласовать, расширяем ли специализацию M7Legal за пределы юридического сопровождения сделок с Китаем.
2. Перенести и стилистически унифицировать существующие SEO-страницы (без смены URL).
3. Подтвердить реальные кейсы и разрешения на публикацию.
4. Сделать staging-копию и протестировать форму/Метрику/мобильные экраны.
5. Заменять боевой сайт только после резервной копии и явного одобрения.

Никаких GitHub Actions и новых платных сервисов.
